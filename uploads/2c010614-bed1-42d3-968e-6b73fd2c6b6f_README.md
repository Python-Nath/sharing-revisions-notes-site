# Atelier CV

Générateur de CV dans le navigateur, en français et en anglais.

Le texte, la photo et la mise en page restent sur cet appareil (stockage local). Rien n’est envoyé à un serveur.

## Lancer

```bash
npm install
npm run dev
```

Puis ouvrir l’adresse affichée par Vite, en général http://localhost:5173.

## Ce que vous pouvez faire

- Rédiger le CV en français ou en anglais (les titres de rubriques suivent la langue du document)
- Changer la langue de l’interface sans toucher au texte
- Ajouter une photo, la masquer, choisir un cercle ou un carré
- Choisir un modèle : éditorial, classique ou minimal
- Régler la couleur et la densité pour tenir sur une page A4
- Masquer des rubriques, réordonner les expériences, formations, compétences
- Exporter un PDF via la fenêtre d’impression (A4, marges aucune, graphiques d’arrière-plan)
- Télécharger ou réimporter une sauvegarde JSON

Un exemple complet est chargé au premier lancement. Le menu Exemples permet de le retrouver.
